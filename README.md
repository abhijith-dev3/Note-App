# 📒 Note App (Full Stack MERN)

A modern full-stack note-taking application built using **React (Vite)** for the frontend and **Node.js + Express + MongoDB** for the backend.  
It includes authentication, protected routes, and full CRUD functionality for notes with a clean UI.

---

## 🚀 Live Demo

- 🌐 Frontend: https://note-app-theta-topaz.vercel.app/ 
- ⚙️ Backend API: https://note-app-mxiy.onrender.com

---

## ✨ Features

### 🔐 Authentication
- User Registration
- User Login
- JWT-based authentication
- Persistent login using localStorage

### 🧾 Notes Management
- Create notes
- View notes
- Delete notes
- Real-time UI updates

### 🔒 Security
- Protected routes (frontend + backend)
- JWT token verification
- Secure API requests using Axios interceptors

### 🎨 UI/UX
- Clean and modern interface
- Responsive design
- Tailwind CSS styling

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- React Router DOM
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs
- CORS
